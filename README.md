# ScreenCutter

Windows 11 の画面の一部を静止画として切り出すツールです。登録しておいたサイズの枠のほか、ドラッグで囲んだ範囲、定規付きの枠、ウィンドウ、画面全体でも切り出せます。タスクトレイに常駐し、ホットキーで呼び出します。

## 起動

[Releases](../../releases) から最新の `ScreenCutter.exe` をダウンロードし、ダブルクリックします。タスクトレイ（通知領域）にアイコンが出たら準備完了です。

初回に「.NET Desktop Runtime が必要」と表示された場合は、表示されたリンクから **.NET 8 Desktop Runtime (x64)** をインストールしてください。コマンドなら `winget install Microsoft.DotNet.DesktopRuntime.8` でも入ります。

## 使い方

1. 起動キーを押す（既定は **Ctrl + Alt + S**）
2. 画面が一時停止した状態になり、**固定サイズ**の選択枠が表示される
3. マウスで枠を移動する
4. **左クリック** でキャプチャして保存
5. **Esc** または **右クリック** で中止

### モードの切り替え

起動後、次のキーでモードを切り替えられます。いつでも Esc / 右クリックで中止できます。

| キー | モード | 内容 |
| --- | --- | --- |
| （起動時） | 固定サイズ | 登録サイズの枠がマウスに追従。左クリックで保存 |
| **F** | 自由サイズ | ドラッグで範囲を囲み、ボタンを離すと保存。もう一度 F で固定サイズに戻る |
| **S** | スケール | 500 × 500 から始まる枠の上下左右に、ピクセル数を測る定規を表示。もう一度 S で固定サイズに戻る |
| **W** | ウィンドウ | 押すたびに「描画ペイン → ウィンドウ全体 → 画面全体 → 固定サイズ」の順に切り替え |

**W キーの押下回数とモード**

| 回数 | 切り抜く範囲 |
| --- | --- |
| 0 | 固定サイズ |
| 1 | マウスが載っているウィンドウの描画ペイン（タイトルバーや枠を除いた中身） |
| 2 | マウスが載っているウィンドウ全体 |
| 3 | マウスがあるディスプレイ 1 画面分 |
| 4 | 固定サイズに戻る |

ウィンドウモードでは、マウスを動かすと対象のウィンドウが枠で示されます。左クリックで保存します。

### 各モードの補助操作

| モード | 操作 | 内容 |
| --- | --- | --- |
| 固定サイズ | ↑ / ↓ | 登録サイズの一覧を枠内に表示（現在のサイズは黄色で「← 現在」）。続けて ↑↓ で選び、**Enter で決定**、Esc で一覧を閉じる |
| 固定サイズ | マウスホイール / 1〜9 キー | 登録サイズを直接切り替え |
| 固定サイズ | ← / → | カーソルを 1px 移動（Shift で 10px） |
| 自由・ウィンドウ | 矢印キー | カーソルを 1px 移動（Shift で 10px） |
| スケール | ↑ / ↓ | 高さだけを 100px 大きく / 小さく |
| スケール | → / ← | 幅だけを 100px 大きく / 小さく（幅・高さとも最小 100） |
| すべて | Tab | 保存形式を PNG → JPG → WebP の順に切り替え（枠の上の表示に現在の形式が出ます。変えた形式は次回以降も使われます） |
| すべて（WebP のとき） | Ctrl + ↑ / ↓ | WebP の品質を 10 ずつ上げ下げ（10〜100。変えた品質は次回以降も使われます） |
| すべて | Enter / Space | 左クリックと同じく保存（サイズ一覧を開いているときの Enter はサイズの決定） |

スケールモードの定規は目安として表示するもので、保存される画像には含まれません。

ファイル名の `{name}` は、固定サイズではサイズの名前、それ以外では「自由」「スケール」「ウィンドウ内」「ウィンドウ」「画面」になります。

## トレイメニュー

アイコンを右クリックすると次のメニューが出ます。ダブルクリックで設定画面が開きます。

- キャプチャ開始
- 切り出しサイズ（ここで有効なサイズを切り替え）
- 保存先フォルダを開く
- 設定...
- 終了

保存時の通知をクリックすると、保存したファイルをエクスプローラーで表示します。

## 設定

| 項目 | 内容 |
| --- | --- |
| ホットキー | 起動キー。ボックスを選んでキーの組み合わせを押すと登録されます |
| 切り出しサイズ | 名前・幅・高さを複数登録。追加 / 削除 / 並べ替えができます |
| 保存先フォルダ | 既定は `ピクチャ\ScreenCutter` |
| ファイル名 | 下の記号を組み合わせて指定します（既定 `SC_{date}_{time}_{seq:4}`） |
| 次の連番 | 次に使う番号。日付が変わったら 1 に戻すこともできます |
| ファイル形式 | PNG / JPG / WebP。JPG と WebP は品質 (1〜100) を指定できます |
| その他 | クリップボードへのコピー、保存時の通知、Windows 起動時の自動起動 |

### ファイル名に使える記号

| 記号 | 例 | 内容 |
| --- | --- | --- |
| `{date}` | 20261027 | 日付 (yyyyMMdd) |
| `{time}` | 153012 | 時刻 (HHmmss) |
| `{date:書式}` | `{date:yyyy-MM-dd_HH-mm-ss}` → 2026-10-27_15-30-12 | .NET の日時書式で自由に指定 |
| `{seq}` | 001 | 連番（既定 3 桁） |
| `{seq:桁数}` | `{seq:5}` → 00001 | 桁数を指定した連番 |
| `{w}` `{h}` | 1280 / 720 | 切り出した幅・高さ |
| `{name}` | フルHD | サイズの名前 |

同じ名前のファイルがすでにある場合は、連番を進めて上書きを避けます（連番を使わない名前なら末尾に ` (2)` などを付けます）。

設定は `%APPDATA%\ScreenCutter\settings.json` に保存されます（設定画面の下部にも表示されます）。

## 補足

- 高 DPI（表示スケール 125% / 150% など）や複数モニタに対応しています。サイズはすべて実際のピクセル数です。
- 登録サイズが画面より大きい場合は、画面に収まるサイズに縮めて切り出します。
- 二重起動はしません。

## ソースからビルドする

`src` フォルダに C# (.NET 8 / WinForms) のソースがあります。画像のエンコードには SkiaSharp を使っています。

```
cd src
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o ..\dist
```

.NET ランタイムのインストールが不要な exe にしたい場合は `--self-contained true` に変えてください（ファイルサイズは約 75MB になります）。
